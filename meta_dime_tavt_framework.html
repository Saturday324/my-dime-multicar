Meta-DIME × TAVT 融合框架

目标是在 Meta-RL 中同时获得两类能力：Meta-DIME 的上下文条件扩散策略与多任务快速适应能力， 以及 TAVT 面向 OOD 任务的虚拟任务生成、任务表示约束和状态正则能力。

Context Encoder q(z|c) Diffusion Policy πθ(a|s,z) Virtual Task zα Task Decoder p(r,s'|s,a,z) Multi-Agent MetaDrive

一句话概括

用 TAVT 在任务潜变量空间中构造“可解释的虚拟任务”，再把真实任务和虚拟任务同时送入 Meta-DIME 的扩散 actor-critic 更新，使策略不仅会根据上下文适应任务，还能覆盖训练分布外的任务变化。

1. 融合后的总体框架图

真实交互数据 任务表示学习 TAVT 虚拟任务生成 Meta-DIME 扩散 actor-critic

2. 两个方法如何融合

Meta-DIME 保留的核心

使用上下文编码器从任务轨迹中得到 z，将 z 拼接到观测上，形成 任务条件扩散策略 和 critic 输入。策略不直接输出动作分布参数，而是通过扩散采样生成动作。

πθ(a|s,z) = DiffusionDenoiseθ(s ⊕ z, ε)

TAVT 注入的核心

在潜变量空间中对多个任务表示做 Dirichlet 混合，得到虚拟任务 zα。 通过 task decoder 预测虚拟任务的 reward 和 next state，再用判别器、循环一致性和状态正则约束其真实性。

zα = α1z1 + ... + αMzM, α ~ Dirichlet(1)

融合后的训练对象

每次更新同时包含真实任务 batch 和虚拟任务 batch。真实 batch 训练基础适应能力， 虚拟 batch 扩展任务覆盖范围，让扩散策略在未见任务附近也能学习稳定动作生成。

L = Lreal-DIME + λvt Lvirtual-DIME + Lrep + Ldecoder

3. 训练流程图

采集多任务轨迹

在多个 MetaDrive 训练任务中采样多智能体 transition，并按 task_id 写入 replay buffer。

推断真实任务 z

从每个任务采样 context，经过 qφ(z|c) 得到任务后验；query batch 用于 actor-critic 更新。

构造虚拟任务 zα

从 M 个任务表示中做 Dirichlet 混合，生成位于任务间隙或 OOD 边界附近的任务表示。

生成虚拟转移

task decoder 根据 (s,a,zα) 预测 rα 和 s'α，并用判别器/循环一致性过滤不可信虚拟样本。

联合优化扩散策略

真实 transition 和虚拟 transition 同时更新 diffusion actor、distributional critic 与 context encoder。

4. 模块对应关系

模块 来自 Meta-DIME 来自 TAVT 融合后的作用
任务上下文编码 ContextEncoder 输入 (s,a,r,s',done)，输出 μ/logvar/z。 PEARL 风格 ψ 编码器、on/off policy 表示缓冲。 统一为 qφ(z|c)，同时服务快速适应和虚拟任务构造。
策略模型 Diffusion policy 通过去噪过程生成连续动作。 原 TAVT 使用 SAC actor。 将 TAVT 的虚拟任务训练信号接入 Meta-DIME 的 diffusion actor。
虚拟任务 原 Meta-DIME 主要在已有任务后验上训练。 Dirichlet 混合 zα，生成未观测任务表示。 扩展训练任务覆盖范围，提升 OOD 泛化。
动力学/奖励建模 critic 通过 Bellman target 学习价值。 task decoder 学习 p(r,s'|s,a,z)。 为虚拟任务提供可训练的 reward 和 next state。
稳定性约束 分布式 critic、target network、entropy cost。 bisimulation、same-task、on/off alignment、WGAN、state regularization。 避免虚拟任务漂移，降低状态变化任务中的价值高估。

5. 损失函数设计

真实任务 Meta-DIME 损失

对真实 query transition 计算 distributional Bellman target，并更新 critic； diffusion actor 通过 critic 指导生成低代价、高价值动作；context encoder 由 critic loss、KL 和任务分类辅助损失共同训练。

Lreal = Lcritic(s,z,a,r,s') + Lactor-diff + βKL(qφ(z|c)||N(0,I)) + γLtask-cls

TAVT 虚拟任务损失

虚拟任务损失由表示约束、解码器重构、对抗一致性、循环一致性和虚拟 Bellman 误差组成。 其中 state regularization 可把预测 next state 与真实 next state 加权，缓解虚拟状态过远导致的 Q 过估计。

Lvt = Lrecon + λbisimLbisim + λwganLadv + λcycleLcycle + λQ Lvirtual-Q + λregLstate-reg

报告中可以强调：TAVT 并不是替换 Meta-DIME，而是给 Meta-DIME 增加“任务空间数据增强”和“虚拟任务约束”。 因此最终优势来自扩散策略的强表达能力与任务潜变量空间的 OOD 扩展能力叠加。

6. 推理/测试阶段

无上下文或冷启动

使用 prior z=0 或从训练任务表示缓冲中采样初始化。此时 diffusion policy 生成的是任务无关的保守动作。

少量交互后快速适应

将最近 K 步 transition 输入 context encoder 得到 posterior z，再用 πθ(a|s,z) 执行动作。 若遇到 OOD 任务，TAVT 训练过的虚拟 zα 会让策略对任务间插值/外推更稳健。
